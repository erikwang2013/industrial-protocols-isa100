# ISA100.11a 协议包 — 需 Yokogawa YFGW410 / Honeywell OneWireless 桥接

> [English](README.en.md)

ISA100.11a (ISA-100.11a Wireless) 工业无线传感器网络协议（IEEE 802.15.4）。需要 Yokogawa 或 Honeywell 无线网关，通过内核 Bridge 层桥接。

## 安装

```bash
composer require erikwang2013/industrial-protocols-isa100
```

## 功能

ISA100.11a 无线网络桥接、BridgeConnector 连接管理

## 所需硬件

Yokogawa YFGW410 现场无线网关、Honeywell OneWireless

## 兼容框架

Laravel / Webman / Hyperf / ThinkPHP / Yii2 / Plain PHP

## 系统要求

- PHP >= 8.1
- ISA100.11a 无线网关
- erikwang2013/industrial-protocols-kernel
